# NEST — UI Screen Specification
## Customer mobile
### Splash
Logo animation, tagline, no interaction.

### Location
Primary CTA: Use current location.
Secondary: Search area manually.

### Home
Greeting, location, problem input, quick categories, Available Now, Your People, Home Passport.

### Problem Assistant
Large input, voice, photo/video, AI response, editable service classification.

### Professional Results
Recommended card first. Filter/sort. Show why recommended.

### Professional Profile
Hero, Trust Score, verification, service menu, portfolio, reviews, availability, book CTA.

### Booking
Service, address, date/time, notes, attachments, estimate, cancellation terms.

### Active Booking
Timeline, ETA, professional info, chat/call, safety/help.

### Extra Work
Clear reason, evidence, amount, approve/reject.

### Review
Rating, tags, comments, rebook/favorite.

### Home Passport
Assets, service history, warranty, next due date.

## Professional mobile
Prioritize "what do I need to do now?"
Home: online status, next job, earnings.
Jobs: actionable queue.
Job detail: location, problem, customer notes, accept.
In-progress: start, timer if appropriate, extra work, complete.
Business: profile, services, portfolio, reviews, availability.

## Admin web
Dense but clean. Data tables, filters, auditability. Do not use the consumer visual style for every admin component.

## Design QA checklist
- Does the screen have one clear primary action?
- Is the price/estimate understandable?
- Is important status accessible without color?
- Can a first-time user understand the next step?
- Are error and empty states designed?
- Are touch targets accessible?
- Does the screen follow the design tokens?
