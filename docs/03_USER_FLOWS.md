## Available Now flow
Home → Need help now → category → nearby available professionals → ETA + price/estimate → choose → confirm → track.

## Rebook flow
Home → Your People → professional → Book again → service/date/address → confirm.

## Home Passport flow
Home → My Home → asset → history → next recommended maintenance → book.

## Professional onboarding
Splash → login → personal details → business details → service categories → service areas → documents → payout details → availability → review → admin verification → approved → online.

## Professional job
Job request → accept → navigate → arrive → start → work → optional extra-work request → upload evidence → complete → customer payment/review → earnings.

## Admin verification
Queue → professional → inspect documents → approve/reject/request changes → audit event.

## Dispute flow
Customer/professional → report issue → select reason → attach evidence → support review → contact parties → resolution → refund/credit/closure → audit log.

## Navigation

Home / Explore / Bookings / You
