# NEST Product Blueprint

This folder is the source-of-truth product package for building NEST with Claude Code.

## Recommended build order
1. Read all docs.
2. Create monorepo skeleton.
3. Set up CI, lint, TypeScript, environment management.
4. Build auth and user/address models.
5. Build services/professionals.
6. Build booking state machine.
7. Build customer app booking flow.
8. Build professional app job flow.
9. Build admin verification/support.
10. Integrate maps, notifications and payments.
11. Add reviews/Trust Score.
12. Add Home Passport.
13. Add AI problem assistant.
14. Test staging.
15. Launch a narrow Belagavi pilot.

## Important
Do not ask Claude Code to implement the whole product in one prompt. Implement one vertical slice at a time and test after every slice.

## Working name
NEST. Brand name is not final.
